# Catálogo Digital con Pedidos por WhatsApp para Comercios Locales

**Fase 1: Maquetación (HTML5 Semántico y CSS)**

## Descripción del Proyecto
Este proyecto consiste en la maquetación web inicial de un catálogo digital orientado a comercios locales, con el objetivo de facilitar la consulta de productos y la estructuración de pedidos para su posterior canalización por WhatsApp.

En esta **Fase 1** se trabaja únicamente la maquetación visual y estructural (sin lógica de envío real ni backend todavía):
- **Dos páginas enlazadas:** página de inicio (`index.html`) y página con formulario maquetado (`pedido.html`).
- **HTML5 semántico:** uso de `<header>`, `<nav>`, `<main>` y `<footer>`, además de lista(s), imagen(es) y enlaces de navegación.
- **Hoja de estilos externa (`css/styles.css`):** enlazada a ambas páginas, con una paleta de colores coherente y selectores de etiqueta, de clase y de ID.
